# Security policy

OpenTrust handles phone numbers that other merchants have reported, so we take security reports seriously.

## Reporting a vulnerability

Please **don't open a public issue** for anything that could put merchants' or other people's data at risk.
Email **jimish@paritycube.com** with:

- what you found and where (URL, endpoint or file),
- steps to reproduce it,
- what an attacker could do with it.

We'll acknowledge your report, keep you updated while we fix it, and credit you when it's fixed if you'd like.
Please give us a reasonable chance to fix the problem before you disclose it publicly, and don't access, change or
delete other people's data while testing. Use your own test account and made-up phone numbers only.

## What is in scope

The website and API at opentrust.in, the code in this repository, the Ruby and Node libraries, the WooCommerce plugin and
the Shopify app.

## Please never put real phone numbers or customer data in an issue, a test or a screenshot.

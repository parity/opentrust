# Brand assets

`opentrust-logo-original.png` is the master (transparent PNG, bird + wordmark). Everything else is generated from it by
`scripts/build_brand_assets.py`: the header logo and bird mark, favicon and home-screen icons, the social-share card
(`public/og-image.png`), the Shopify app icon (`integrations/shopify/assets/app-icon-1200.png`) and the WordPress.org
plugin icons (`integrations/woocommerce/wordpress-org-assets/`).

Wordmark colour is `#182010`; the bird is black and cream (`#E9D4B1`). The site sits the logo on `#EEEFE9`.
